# Data provenance

The county-level TB-demographics dataset used in the original UCL BENG0091 coursework was supplied within the module. It is intentionally **not redistributed** by the public repository.

To reproduce the coursework-data reports locally, place the authorised file at:

`data/raw/TB_demographics.csv`

All source modules and tests can also run from the deterministic synthetic generator (`--synthetic` where supported). The synthetic data reproduce the schema and rough numerical scales only; they are not epidemiological data.
